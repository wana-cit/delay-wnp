# Command Delay Calculator · KNACKSAT-2

เครื่องมือวางแผนเวลาส่งคำสั่ง (uplink) และเวลาถ่ายภาพเป้าหมายของดาวเทียม KNACKSAT-2 — CDH Team

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (เลย์เอาต์ + สไตล์) |
| `core.js` | ส่วนคำนวณล้วน (SGP4, มุมเงย, ดวงอาทิตย์, ค้นหารอบ) ใช้ได้ทั้งเบราว์เซอร์และ Node |
| `app.js` | ตัวควบคุมหน้าจอ (แผนที่ ตาราง ปุ่ม) |
| `i18n.js` | คำแปล 3 ภาษา ไทย / English / 中文 |
| `globe.js` | ลูกโลกสด (d3) แสดงดาวเทียม ณ ปัจจุบัน กลางวัน/กลางคืน แนวโคจร |
| `assets/` | โลโก้ INSTED (สีน้ำเงินสำหรับโหมดสว่าง สีขาวสำหรับโหมดมืด ตราสัญลักษณ์สำหรับมือถือ) และ favicon |
| `land.json` | เส้นขอบทวีป Natural Earth 1:110m (public domain) สำหรับลูกโลก |
| `test.js` | ชุดทดสอบ — `npm install && npm test` |
| `command-delay-calculator.html` | ลิงก์เก่า เปลี่ยนเส้นทางไปที่ `index.html` |

เปิดใช้งาน: วางทั้งโฟลเดอร์บน GitHub Pages หรือเปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้

## สิ่งที่เปลี่ยนในเวอร์ชัน 2.0

**แก้ไขความถูกต้อง**
- เป้าหมาย Paris เดิมชี้ไปที่ “จุดกึ่งกลางประเทศฝรั่งเศส” (46.6034, 1.8883) ห่างหอไอเฟล ~253 km — แก้เป็น **หอไอเฟล 48.858370, 2.294481**
- เดิมระบบอาจเลือก **รอบส่งคำสั่งที่ผ่านไปแล้ว** (ย้อนหลังจากเวลาถ่ายภาพโดยไม่เช็กเวลาปัจจุบัน) — ตอนนี้บังคับให้เป็นรอบในอนาคต และก่อนเวลาถ่ายภาพอย่างน้อย “เวลาเผื่อขั้นต่ำ”
- ใส่ค่า 0 ในช่องเงื่อนไขไม่ได้ (ระบบแทนเป็นค่าอื่นเงียบ ๆ) และค่าสำรองไม่ตรงกับค่าเริ่มต้น — แก้แล้ว พร้อมตรวจช่วงค่าที่ถูกต้อง
- ช่องลิงก์ Google Maps เด้งแจ้งเตือน/ลบข้อความระหว่างพิมพ์ — เปลี่ยนเป็นตรวจเมื่อวาง/กด Enter และรองรับลิงก์แบบ `!3d…!4d…`
- เมื่อทั้งสถานีและเป้าหมายเป็นแบบกำหนดเอง คลิกแผนที่ได้แค่สถานี — เพิ่มตัวเลือก “ปักหมุด: สถานี / เป้าหมาย”
- มุมเงยใช้แบบจำลองโลก WGS-84 ของ satellite.js แทนโลกทรงกลม และหาเวลาสูงสุดละเอียดถึง 0.1 วินาที
- วงรัศมีสื่อสารวาดรอบตำแหน่งดาวเทียม **ขณะส่งคำสั่ง** (เดิมวาดที่ขณะถ่ายภาพ)

**ฟังก์ชันใหม่**
- แสดงช่วงส่งคำสั่ง AOS / TCA / LOS และ delay หากส่งที่ต้นหรือท้ายรอบ
- อายุ TLE + ปุ่มดึง TLE ล่าสุด (ลอง SatNOGS DB ก่อน แล้วค่อย CelesTrak)
- เมื่อไม่พบรอบ บอกเหตุผล (เช่น แสงอาทิตย์ไม่พอ) พร้อมปุ่มลองใหม่ด้วยค่าที่แนะนำ
- ตารางทุกรอบพร้อมสถานะ ตัวกรอง “เฉพาะรอบที่ใช้ได้” และส่งออก CSV
- ปุ่มคัดลอกสรุปแผน สำหรับส่งต่อทีม
- จำค่าที่ตั้งไว้ในเบราว์เซอร์, คีย์ลัด Ctrl/⌘ + Enter

**หน้าจอ**
- คอม (≥1360px): 3 คอลัมน์ — ตั้งค่า | แผนที่ + ตาราง | ผลลัพธ์
- แล็ปท็อป/แท็บเล็ตแนวนอน: 2 คอลัมน์
- แท็บเล็ตแนวตั้ง/โทรศัพท์: แถบเมนูล่าง ตั้งค่า · แผนที่ · ผลลัพธ์ · รอบ

## ติดตามดาวเทียมสด (v2.3)
- เปิดเว็บแล้วเห็นตำแหน่งดาวเทียม ณ ขณะนี้ทันที (คำนวณจาก TLE ในช่องด้วย SGP4 ทุก 1 วินาที ไม่ต้องใช้อินเทอร์เน็ต)
- ลูกโลกหมุนตามดาวเทียม ลากหมุนเอง/เลื่อนซูมได้ ปุ่ม "ติดตามดาวเทียม" เพื่อกลับมาตาม
- แสดงด้านกลางวัน/กลางคืนตามตำแหน่งดวงอาทิตย์จริง แนวโคจรย้อนหลังครึ่งรอบและล่วงหน้า 1 รอบ วงรัศมีสื่อสาร
- แผง "สด": อยู่ในระยะติดต่อหรือไม่, นับถอยหลังถึง AOS ถัดไป (หรือถึง LOS ถ้ากำลังติดต่อ), ละติจูด/ลองจิจูด/ความสูง, มุมเงย/ทิศ/ระยะจากสถานี
- ตรวจกับ Skyfield: ตำแหน่งต่างไม่เกิน 0.05 km, มุมเงย/ทิศต่างไม่เกิน 0.001°, เวลา AOS/LOS ต่างไม่เกิน 0.25 วินาที
